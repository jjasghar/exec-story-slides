# exec-story-slides

## Why?

So I've found myself having to convince executives to invest in projects I think
can benifit my team or company. I've been trying to figure out a way to create
a repeatable story and template to create the presentation. This is what I've
come up with.

It is split up into 9 buckets of things to tell the story in a convincing manner
to them. It starts from the "why" and builds to the "what", then "how" finally
to "asks." You obviously can remove sections or expand them if needed, but
the framework can build to why you are there trying to convince them of something.

This is a simple [reveal.js](https://revealjs.com/markup/) because I wanted something
I could spend the time on thinking about the story, more so then the formatting
or pictures like PowerPoint. Remember, this should be used to augment your
conversation with your leadership, not something you just "send to them."

If you're looking for that level of detail, there are many other ways to build
out of this outline to get there, but this is more for the interation(s) instead
of the formal review.
